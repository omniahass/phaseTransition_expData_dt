# docs

`pipeline_report.md` is the **single source** for the pipeline write-up.

Edit that file. Everything else — the published artifact, any Word or PDF
export — is generated from it and must not be edited by hand, or the copies
drift apart and it stops being obvious which one is right.

Both Omnia and Claude edit this file directly, so git is what keeps us from
overwriting each other. Pull before editing, commit when done.
